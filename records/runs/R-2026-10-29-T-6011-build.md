## What is different now

A person (or an agent under their yes and a grant) can see what a pack move brings before taking it: `bonsai pack
set` lists the pack's own commit titles between the two versions, and `bonsai pack outdated --changes` does so for
every pack behind. `bonsai pack set --all` moves every pack behind in one preview. `bonsai pack show <id>` prints one
pack's details offline. A Claude Code session opens with a line naming the packs behind. A move back to an older
release needs `--downgrade`, and a version this machine cannot run (a newer Claude Code needed, or a pack format
this Bonsai cannot read) is refused before anything is written. After `--yes`, Bonsai prints the two commands that
commit what it wrote, and names the old plugin marketplace with the command that removes it.
