## What is different now

When an agent writes a date or a time into a task, a run report, STATE, a memory note or a pack document's stamp
field (a plan's `approved`, a decision's `date`, an options write-up's `decided`) where there was none, the guard now
holds it to Bonsai's clock: a time within 10 minutes of the UTC now, a day not after the UTC today nor more than 2 days
before it. A guess is refused with `time-not-now`, the value it saw and Bonsai's UTC now, and the next step `bonsai
now` (or `bonsai now --day`). It works in both status_writes modes. Corrections of a value already there, a value
taken back to null and untouched values pass. Rung 0 does not judge the clock. Command mode's other tripwires still
ignore memory notes. Base's task, run, memory and operating skills say to take every time from `bonsai now`, in UTC;
base:run says the hours are the sessions table's per-task rows.
