## What is different now

An agent or a person can file a bug with one command (`bonsai bug add --title ...`), which takes the next free
`BUG-` number and writes the bug's own file in the main checkout, and move it with `bonsai bug fix <id> --commit
<sha>`, `wontfix`, `watch` or `reopen`, change its text with `bonsai bug edit`, and read them with `bonsai bug list`
and `show` (`--json` for programs). An old register's bug is carried over with `bonsai bug add --was <old id>`. Every
write is logged with who made it. In every project, whatever the task switch `status_writes` says, the guard refuses
a hand edit of a bug's status line and names `bonsai bug`; the bugs page is locked against hand edits only once it is
the generated page (it carries the marker), so a register not moved yet stays an ordinary file. Tasks are held
exactly as before.
