# Run: Time, piece E: now told on each prompt and each subagent start

> Opened at the start of the session and added to as it goes. Not written at the end.

## What is different now

Every prompt and every subagent in a linked project now opens with one line telling the model the time:
`Now: 2026-10-21 08:19 UTC (local 13:49 +05:30)`, with the local date added when the local day differs from the
UTC day. Agents can copy times from that line and do not have to guess them. A project takes the two new hook lines
at the director's `bonsai update --allow-exec --yes`; until then `bonsai check` warns (own-hooks). The line never
stops a prompt. That holds when bonsai is missing, when it is a build too old to know `hook now` (rc.1 answers exit
2), and when it crashes, because the line ends `|| exit 0`.
