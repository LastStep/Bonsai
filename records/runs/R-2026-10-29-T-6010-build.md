## What is different now

A person can move a project's pack to another version with one command, `bonsai pack set base@base-v1.0.1`, add one
(`pack add`) or take one out (`pack remove`): each shows one preview, the bonsai.yaml line and everything the update
changes, and `--yes` writes it all or nothing, keeping the line's own comment. `bonsai pack outdated` lists which
packs have a newer release, and plain `bonsai status` then shows the same offline. A change that takes protections
away is the person's alone: an agent's `--yes` on it is refused, for a hand edit and `bonsai update` too. Bonsai's own
"newer release" line no longer calls an installed 1.0.1 current against a stale 1.0.0 record (BUG-139).
